Hardening Auditor, audit de conformité CIS et ANSSI

Un outil d'audit en lecture seule pour serveurs Windows et Linux, fondé sur les CIS Benchmarks et le guide d'hygiène de l'ANSSI. Un collecteur sans dépendance (PowerShell 5.1 ou sh POSIX) relève la configuration dans un fichier JSON sans rien modifier, puis un moteur Python l'évalue : score par catégorie, contrôles en échec avec leur remédiation, rapport HTML hors ligne et exports pour le SIEM. Conçu pour mon alternance chez Eurocom Broadcast.

  • 70 contrôles YAML (35 Windows, 35 Linux)
  • 6 systèmes réels audités à chaque commit
  • 148 tests, 99 % de couverture
  • 0 dépendance sur le serveur audité
